## Tujuan Proyek

Proyek ini bertujuan memprediksi kejadian hotspot harian di Provinsi Kalimantan Tengah berdasarkan faktor meteorologi menggunakan metode Ensemble Random Forest dan XGBoost.

## Metode

1. Pengumpulan dan preprocessing data.
2. Exploratory Data Analysis (EDA).
3. Pemodelan Random Forest dan XGBoost.
4. Hyperparameter tuning menggunakan RandomizedSearchCV.
5. Evaluasi model menggunakan Accuracy, Precision, Recall, F1-score, dan PR-AUC.
6. Penggabungan prediksi menggunakan soft voting ensemble.

## Pembagian Tugas

- Niki: Pengumpulan data, preprocessing, dan EDA.
- Hikmal: Pemodelan Random Forest dan XGBoost serta hyperparameter tuning.
- Nia: Ensemble, evaluasi perbandingan model, dan dokumentasi proyek.
